
# Django Multi-Route Portal

## Project Description
A Django project developed for the Week 10 and Week 11 activities.

## Features
- Django URL routing
- Item model for inventory records
- Database migrations
- Django Admin registration
- Add and manage inventory items through Django Admin

## Technologies
- Python
- Django
- SQLite (local development database)

## How to Run
1. Install Python.
2. Install Django: `python -m pip install django`
3. Open the project folder in the terminal.
4. Run migrations: `python manage.py migrate`
5. Start the development server: `python manage.py runserver`
6. Open `http://127.0.0.1:8000/admin/` in your browser.

Create a superuser with `python manage.py createsuperuser`
if you need to access the admin interface.
